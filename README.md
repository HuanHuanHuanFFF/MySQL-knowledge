# MySQL Knowledge Distillation

一个面向机制理解、后端面试复习与长期知识沉淀的 MySQL 知识蒸馏库。  
A distilled MySQL knowledge base for understanding core mechanisms, preparing for backend interviews, and long-term knowledge management.

---

## 简介 / Overview

本仓库基于 MySQL 官方文档及其他公开资料，借助 AI Agent 辅助整理与重构，并结合个人学习笔记、面试复盘和长期复习需求，整理为适合 Obsidian 阅读的结构化 MySQL 知识库。

This repository is based on MySQL official documentation and other public resources. It is organized and restructured with the help of AI agents, combined with personal study notes, interview review, and long-term learning needs, and structured for Obsidian-based reading and review.

---

## 目标 / Goals

这个仓库不是简单的资料堆积，而是尝试把 MySQL 相关知识整理成更容易理解、复习和迁移的知识结构。

This repository is not just a collection of materials. It aims to reorganize MySQL knowledge into a structure that is easier to understand, review, and apply.

主要目标：

- 理解 MySQL 核心机制，而不是只背结论
- 面向后端面试进行系统复习
- 将零散知识点整理成可长期维护的知识库
- 适合使用 Obsidian 进行双链、复习和知识追踪

Main goals:

- Understand MySQL core mechanisms instead of only memorizing conclusions
- Support systematic review for backend interviews
- Organize scattered knowledge into a maintainable knowledge base
- Make the content suitable for Obsidian-based linking, review, and knowledge tracking

---

## 内容范围 / Scope

当前内容主要包括：

- SQL 基础
- 表结构与字段设计
- 索引与 B+ 树
- InnoDB 存储引擎
- 事务与隔离级别
- MVCC
- undo log / redo log / binlog
- 查询执行流程
- 慢查询与优化思路
- 常见后端面试问题整理

Current topics include:

- SQL basics
- Table schema and field design
- Indexes and B+ Trees
- InnoDB storage engine
- Transactions and isolation levels
- MVCC
- undo log / redo log / binlog
- Query execution flow
- Slow query analysis and optimization
- Common backend interview questions
